# Mohammad Wasifullah Nasim — Portfolio Website

A premium dark-mode portfolio website built for a Data Analyst & AI student.

## Files
- `index.html` — The complete single-file portfolio (all CSS + JS included)

## How to Use
1. Simply open `index.html` in any browser — no build step needed.
2. To host it, upload `index.html` to any static hosting (GitHub Pages, Netlify, Vercel).

## Customization
- **Profile photo**: Replace the `src` URL in the `<img>` tag inside the hero section with your own image.
- **Resume download**: Add your PDF resume to the folder and update the "Download CV" button href.
- **LinkedIn / GitHub**: Update the href links in the footer and About section.
- **Projects**: Add more `.project-card` divs in the `#projects-grid` section.

## Tech Stack
- Plain HTML + CSS (no framework dependency)
- Tailwind CSS (via CDN)
- Google Fonts: Plus Jakarta Sans + DM Mono
- Material Symbols Outlined icons
